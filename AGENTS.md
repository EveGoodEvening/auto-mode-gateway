- For Codex internals, shallow-clone `openai/codex` into the scratchpad and grep; file paths guessed from older docs/blogs (`openai_tools.rs`, `model_provider_info.rs`, `chat_completions.rs`) no longer exist. Current locations: tool specs `codex-rs/core/src/tools/handlers/shell_spec.rs` + `apply_patch_spec.rs`; provider config `codex-rs/model-provider-info/src/lib.rs`; Responses SSE parser `codex-rs/codex-api/src/sse/responses.rs`; approval enums `codex-rs/protocol/src/protocol.rs` + `config_types.rs`; Auto-review `codex-rs/core/src/guardian/` + `codex-rs/prompts/templates/guardian/policy.md`.
- Codex (CLI 0.164.0, 2026-10-23) speaks only the Responses API: `wire_api = "chat"` was removed in rust-v0.95.0 (2026-02-04, PR #10498). The shell tool is `exec_command` (+ `write_stdin`), not `shell`/`shell_command`; `--ask-for-approval` accepts only `on-request` | `never`; `--full-auto` is deprecated/removed, `--approve-for-me` and `--yolo` exist.
- C01 bootstrap (2026-10-28, `agent://c01-bootstrap-1`) deliberately pinned TypeScript 5.9.3 and `eventsource-parser` 3.1.1 rather than moving latest majors; these remain the actual selected versions. Parser v3 uses `createParser({ onEvent })`, not the older callback-only form. Actual tsup is 8.5.0 after declaration repairs, not initial 9.0.0. Supported Node remains `^24.11.0 || >=26.0.0` (Node 24.11+, excludes Node 25); see `docs/plan/PROGRESS.md` for historical selections and evidence.
- C01 toolchain: tsup 9.0.0 and 8.5.1 publish declarations importing absent `./types.cts`; use 8.5.0 with exact `@swc/core` 1.16.20 type peer, without skipLibCheck. npm >=12 with engine-strict enforces the supported installer; versioned allowScripts permits esbuild 0.25.12/0.28.2 and denies SWC installer. Refresh approvals when lock changes.
- Register only implemented CLI commands via `register<Name>Command(program: Command): void`, and use `await program.parseAsync()` so asynchronous action failures reach the entrypoint. Preserve Commander-managed version/help behavior and derive the version from package metadata.
- Treat unexpected CLI errors as potentially secret-bearing: never print arbitrary exception messages, causes, stack traces or configuration. Emit a fixed diagnostic and set `process.exitCode = 1`; command-specific actionable diagnostics must be explicitly safe. Token command stdout is an intentional credential output, not a diagnostic or log sink.
- Do not turn staged package scripts into placeholder commands. The staged `eval` script remains unavailable until C12's real implementation/registration. Bootstrap-only empty-suite allowances must not survive introduction of real tests; current verification and acceptance status belongs in `docs/plan/PROGRESS.md`, not these reusable lessons.
- Hono 4.13.14's WebSocket declarations require web-platform `MessageEvent<T>` and `BinaryType`; Node24 standalone ambient types lack that contract. TypeScript `lib: ["ES2024", "DOM", "DOM.Iterable", "DOM.AsyncIterable"]` alongside `types: ["node"]` supplies declaration compatibility and iterable Fetch APIs, not a browser runtime requirement. `DOM.AsyncIterable` specifically declares `ReadableStream[Symbol.asyncIterator]` and `values()`, matching Node24's runtime support for `for await` over Web Streams; `DOM.Iterable` alone covers synchronous iteration only. Use these platform declarations rather than rewriting stream consumers, adding ambient shims or enabling skipLibCheck.
- Protocol parsing is not protection: an explicit allow-only stage belongs only on disposable mock traffic and must be replaced by the actual gate before real agent ingress. Adapt only supported generation endpoints/formats; missing or unsupported generation MIME must fail closed, not open a relay-controlled bypass. Forward original bounded request bytes, never extracted metadata. Malformed/incomplete execution is never approval-eligible. Local/inert fixtures and mock cache fields do not prove real agent behavior or live cache hits; current status and evidence belong in `docs/plan/PROGRESS.md`.
- SSE semantic parsing does not authorize reserialization: retain original raw frames including comments, CRLF, id/retry, unknown events and multiline data, and emit those bytes unchanged unless intentionally rewriting. Text/thinking/ping must not wait for tool decisions. Response hard bounds and idle/completion/decision deadlines apply from C05, independently of inbound body limits; overflow, incomplete EOF, timeout and cancellation must not release unreleased tool execution.
- Validate Anthropic `message_start.message.content` against the supported empty-content streaming shape before forwarding: initial execution snapshots must not bypass tracked tool withholding or approval. Aggregate response accounting must include retained serialized UTF-8 initial tool input as well as raw frames and streamed parameters. Regressions must cover zero-execution/no-approval snapshots and raw-below-cap/aggregate-over-cap initial inputs; reproduce failures before production patches.
